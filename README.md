# zrok Windows ARM64 builds

Automated weekly builds of [zrok](https://github.com/openziti/zrok) for `windows/arm64`.

Each [release](https://github.com/sin3point14/zrok2-win-arm64/releases) here tracks the upstream zrok tag and contains only the `windows/arm64` binary (`zrok2.exe`) with its SHA256 checksum.

The build runs automatically every Monday at 06:00 UTC, or you can trigger it manually via [Actions](https://github.com/sin3point14/zrok2-win-arm64/actions/workflows/build-windows-arm64.yml).
